# GrabKnife4OPTIMISED

Optimised Grab Knife (knife-only) — Roblox client script. Remade by curelessdoktor.

**Controls:** **Z** to equip/unequip, **left click** to grab / kill. R6 and R15 supported; ragdoll + blood effects.
